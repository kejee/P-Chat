# 🔒 P-Chat (Privacy Chat)

> **Zero-Knowledge End-to-End Encrypted & Ephemeral Web Messenger**  
> **零知识端到端加密 · 阅后即焚 · 纯内存无痕运行 · 网页版私密聊天室**

---

## ✨ Features / 核心特性

- **🛡️ 零知识端到端加密 (Zero-Knowledge E2EE)**: 基于浏览器原生硬件加速 `Web Crypto API` (AES-256-GCM + PBKDF2)。所有消息、图片、视频与文件在离开浏览器前完成全量加密，服务端仅作为盲中继，绝不存储且无法解密任何通信内容与口令。
- **📎 全格式富媒体密聊 & 剪贴板直贴**:
  - 支持发送文本、图片、音视频及各类文件附件。
  - **剪贴板直接粘贴**: 在输入框内按下 `Ctrl/Cmd + V` 即可直接粘贴截图并预览加密发送。
  - **沉浸式交互**: 支持图片点击全屏灯箱放大、视频原生播放器播放及一键安全下载附件。
- **⌨️ 极客键盘交互**: 支持 `Shift + Enter` 发送消息，`Enter` 换行输入；发送后自动清空输入框与附件。
- **🚪 三维便捷入口**:
  - **创建群组**: 自动生成防撞高熵强口令，创建者即管理员。
  - **口令直达**: 无需知道群名，直接凭口令寻址并自动派生本地密钥加入。
  - **群组大厅**: 仅展示“公开可见”的群组；无口令群一键加入，有口令群需凭口令进入。
- **🔥 高级阅后即焚 (Burn After Reading)**:
  - 文本与富媒体消息均支持阅后即焚，默认密文/遮罩保护，**长按或点击才触发解密查看**。
  - 支持**倒计时焚毁**（如 5s/10s）与**阅读配额焚毁**（如仅前 N 人可看），达成条件后全员实时粒子粉碎。
- **👁️ 防窥与反作弊保护**:
  - 窗口失焦、Tab 切换或快捷键窥探时自动模糊遮盖消息。
  - 客户端内存生命周期管理，关闭网页立即物理擦除密钥与历史。
- **👑 管理员安全控制台**:
  - 随时切换口令开关（关闭口令时强制联动群组为公开可见，避免群组失联）。
  - **IP 白名单与地域访问控制**: 限制仅允许指定 IP 或网段加入。
  - **群组自毁倒计时**: 设置房间存活时长，倒计时结束服务端与客户端全量物理销毁。
  - **一键核按钮 (Panic Button)**: 紧急情况下瞬间粉碎房间所有数据并强退所有成员。
- **⚡ 纯内存运行 (RAM-Only / Zero-Disk)**:
  - 服务端不使用任何数据库，不写入任何磁盘日志，重启或自毁后痕迹全无。
- **🐳 容器化 & CI/CD**:
  - 生产级 Alpine Docker 镜像，体积 < 50MB。
  - 配置 GitHub Actions 自动构建多架构镜像（amd64 / arm64）并发布到 `ghcr.io`。

## 🏗️ Architecture & Security Model / 安全模型与架构

```
┌────────────────────────────────────────────────────────┐
│                      客户端浏览器                        │
│  ┌──────────────┐   ┌─────────────────┐   ┌─────────┐  │
│  │ 随机强口令派生 │   │  AES-256-GCM    │   │ 阅后即焚 │  │
│  │  (PBKDF2)    │   │  客户端加解密   │   │ 防窥遮罩 │  │
│  └──────┬───────┘   └────────┬────────┘   └────┬────┘  │
└─────────┼────────────────────┼─────────────────┼───────┘
          │ 口令验证哈希        │ 纯密文盲包       │ ACK状态
          ▼                    ▼                 ▼
┌────────────────────────────────────────────────────────┐
│               轻量级 WebSocket 盲中继后端              │
│  - 纯 RAM 内存运行 (无磁盘写盘、零日志泄露)             │
│  - 房间自毁计时器 (物理擦除)                           │
│  - 阅后即焚配额仲裁 & IP 访问白名单/防爆破              │
└────────────────────────────────────────────────────────┘
```

1. **密钥生成与派生**: 房间口令在浏览器中通过 PBKDF2-SHA256（100,000 次迭代 + 房间唯一 Salt）派生出 256 位 AES-GCM 密钥。
2. **零知识验证**: 客户端向服务端仅发送口令的二次 SHA-256 哈希作为房间寻址索引与门禁校验，服务端永远无法逆向还原出口令原文，更无法推导 AES 密钥。
3. **密文广播**: 每条消息在发件人本地生成唯一的 96 位 IV，结合 AES-256-GCM 进行加密；服务端只盲转发 `[IV + Ciphertext + AuthTag]`。

## 🚀 Quick Start / 快速开始

### 方式一：使用 Docker 极速运行 (推荐)

```bash
docker run -d \
  --name p-chat \
  -p 127.0.0.1:3000:3000 \
  --restart unless-stopped \
  ghcr.io/kejee/p-chat:latest
```

> **⚠️ 生产部署环境要求（HTTPS）**：  
> 现代浏览器（Chrome、Safari 等）严格限制仅在 **安全上下文 (Secure Context)** 下启用原生硬件级 `Web Crypto API`。  
> 生产环境**请勿直接将 IP:端口 暴露到公网 HTTP**，请绑定本地 `127.0.0.1:3000`，并通过 **Nginx / Caddy / Cloudflare / 宝塔** 等反向代理并配置 SSL 证书（HTTPS），以确保端到端加密（E2EE）在所有移动端与电脑端 100% 正常运行。

或使用 `docker-compose.yml`:
```bash
docker compose up -d
```
本地可通过 `http://localhost:3000` 直接体验，线上部署通过绑定的 HTTPS 域名访问。

---

### 方式二：源码直接运行

需要 Node.js 18+ 环境：

```bash
# 1. 克隆代码
git clone https://github.com/kejee/P-Chat.git
cd P-Chat

# 2. 安装依赖
npm install

# 3. 启动服务
npm start

# 开发模式（热重载）
npm run dev
```

## 📦 GitHub Actions 自动发布至 ghcr.io

本项目已内置 `.github/workflows/docker-publish.yml`。

1. 将代码推送到 GitHub 仓库（`main` 分支或发布 Tag 如 `v1.0.0`）。
2. GitHub Actions 将自动触发多平台交叉编译（`linux/amd64` 和 `linux/arm64`）。
3. 自动构建并推送到 GitHub Container Registry：`ghcr.io/kejee/p-chat:latest`。
4. 确保在 GitHub 仓库的 **Settings -> Actions -> General -> Workflow permissions** 中勾选 **Read and write permissions**。
